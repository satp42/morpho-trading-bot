# Morpho Strategy Bot

Dynamic strategy bot for identifying and executing highest APY strategies on Morpho across chains.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   ```bash
   cp .env.example .env
   # Edit .env with your keys
   ```

3. Run tests:
   ```bash
   npm test
   ```
